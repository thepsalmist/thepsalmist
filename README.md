### 🧑‍💻 About Me

- 💼 Senior Software Engineer at **[Search Atlas](https://searchatlas.com)** — building Django/DRF/Celery microservices for SaaS reporting on Google Search Console, GA, Google Ads & Meta Ads
- 🌍 Previously at **[Code for Africa](https://codeforafrica.org)** — backend on civic-tech platforms (Mediacloud Story-Indexer, Wazimap-NG, Sensors.Africa, Open.Africa)
- 🔭 Most days: API design, distributed pipelines, **PostgreSQL/ClickHouse** tuning, and production debugging across Sentry, Loki & Grafana
- ⚙️ Sometimes I wander into **DevOps & SRE** — Kubernetes, Ansible, Elasticsearch clusters, OpenTelemetry instrumentation
- 🌱 Currently exploring **Go** and going deeper on distributed systems
- 🪶 Open-source contributor to **Django** and **CKAN**
- 📜 **AWS Certified Solutions Architect — Associate**
